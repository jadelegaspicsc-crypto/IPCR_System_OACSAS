# Workbook reference notes

The supplied workbook was inspected directly with the spreadsheet engine.

Relevant worksheets:
- `IPCR_1ST SEMESTER`
- `IPCR_2ND SEMESTERS`

The second and third worksheets contain the IPCR form structure used as the design reference for v3.

Observed form fields include:
- Output / Outcome
- Success Indicators (Targets + Measures)
- Weight Allocation
- Actual Accomplishments
- Rating:
  - Q = Quality
  - E = Efficiency
  - T = Timeliness
  - A = Average
- Remarks
- Core Functions: 60%
- Strategic Functions: 30%
- Support Functions: 10%
- Final Average Rating
- Comments and Recommendations for Development Purposes
- Employee / Immediate Supervisor / Head of Office sections

The workbook also contains semester-specific target examples and formulas. v3 stores the same core data in normalized Supabase tables so multiple employees can use the system simultaneously.
